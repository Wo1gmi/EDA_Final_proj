# Презентация проекта

Авторы: Анастасия Казакова, Степан Селезнев, Светлана Калошкина.

Для защиты используйте `presentation.pptx` или `presentation.pdf`. Презентация содержит 11 слайдов. Текст и две таблицы редактируются в PowerPoint. Научные графики взяты из `output/figures/` и воспроизводятся основным Python-скриптом проекта.

`build_deck.mjs` выполняет дополнительную программную пересборку оформления через JavaScript и `@oai/artifact-tool`. Этот шаг требует среды с установленным пакетом и инструментами Presentations. Он отделён от воспроизведения расчётов и запуска ноутбука. Презентацию также можно редактировать непосредственно в PowerPoint.

`prepare_content.py` автоматически читает результаты анализа и формирует `slide_content.json` с текстами, численными показателями, ссылками на графики и контрольными суммами. Сборщик запускает этот шаг и проверяет суммы перед экспортом. После изменения данных следует снова выполнить анализ и пересобрать презентацию. Содержательную интерпретацию результатов необходимо проверить при изменении исследовательской выборки или модели.

Пакеты `@oai/artifact-tool` и `jszip` должны быть доступны через `node_modules` выбранной среды. Для программной пересборки задайте `PRESENTATIONS_SKILL_DIR`, `RUNTIME_NODE_MODULES` и `RUNTIME_PYTHON` согласно установленной среде. Запустите `node build_deck.mjs` из каталога `slides`. Результат по умолчанию появится в `.slides-build/presentation.pptx`. `SLIDE_TEMPLATE`, `SLIDE_BUILD_DIR` и `SLIDE_OUTPUT` позволяют отдельно задать исходную презентацию, временный каталог и путь результата. Для каждой новой версии используйте новый путь результата.

PDF экспортируется из итогового PPTX с сохранением шрифтов Calibri и Cambria. Перед защитой проверьте его открытие на компьютере, который будет подключён к проектору.
